𝗨𝘀𝗲𝗱 𝗰𝗮𝗿 𝗜𝗻𝘀𝗽𝗲𝗰𝘁𝗶𝗼𝗻 𝗔𝗴𝗲𝗻𝘁🚗🔍

For my capstone project during the Google AI Agents Intensive, I built a Used Car Multi-Part Inspection Agent. The goal was to enable people to analyze second-hand cars before purchasing, especially those without the technical knowledge.

𝗞𝗲𝘆 𝗧𝗲𝗰𝗵𝗻𝗶𝗰𝗮𝗹 𝗙𝗲𝗮𝘁𝘂𝗿𝗲𝘀:

𝗥𝗲𝘁𝗿𝗶𝗲𝘃𝗮𝗹-𝗔𝘂𝗴𝗺𝗲𝗻𝘁𝗲𝗱 𝗚𝗲𝗻𝗲𝗿𝗮𝘁𝗶𝗼𝗻 (𝗥𝗔𝗚)/𝗖𝗼𝗻𝘁𝗲𝘅𝘁 𝗘𝗻𝗴𝗶𝗻𝗲𝗲𝗿𝗶𝗻𝗴: I integrated real inspection manuals via LangChain to ground the AI’s reasoning.
𝗩𝗶𝘀𝗶𝗼𝗻-𝗟𝗮𝗻𝗴𝘂𝗮𝗴𝗲 𝗠𝗼𝗱𝗲𝗹: Leveraging Google Gemini to analyze and rate each part’s condition directly from the images.
𝗠𝘂𝗹𝘁𝗶-𝗖𝗵𝗮𝗻𝗻𝗲𝗹 𝗣𝗲𝗿𝗰𝗲𝗽𝘁𝗶𝗼𝗻 (𝗠𝗖𝗣): The agent inspects vehicle parts (body, wheels, engine) separately for granular damage and wear analysis.
𝗜𝗻𝘁𝗲𝗿𝗮𝗰𝘁𝗶𝘃𝗲 𝗨𝗜: Built with Gradio for a smooth user experience, providing instant feedback and detailed ratings.
